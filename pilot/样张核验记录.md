完全不同的像素只说明没有完全相同的图像，不代表每张变体彼此独立，也不代表它们容易识别。

## 静态图像初步检查

由助手查看清晰总览、sigma=1 总览、全部六页字对对照和重点位移页，主要展示倍率为 2 倍近邻复制。检查结果是图像质量观察，不是受试者实验，也没有给全部图片赋予“人类可可靠识别”的标签。

| 检查对象 | 观察与后续关注 |
|---|---|
| 81 字清晰总览 | 未见缺字方框、明显拉伸或缺笔裁剪；各字保持共同排版规则下的自然差异 |
| 己／已、已／巳 | 三档模糊下，左侧起点与上部开口仍有可观察区别 |
| 日／曰 | 比例差异保留；本字体中内部横画的右端连接状态也有可观察区别，不能仅以宽高比例解释全部识别线索 |
| 土／士、未／末 | 横画相对长短保留，模糊使边缘柔化，没有把两字变成相同图像 |
| 晴／睛等偏旁变化 | 偏旁形状、框内横画数量等差异在对照图中仍可观察 |
| 辩／辨／辫／瓣，赢／羸／嬴／蠃 | sigma=1 时中央密集构件明显变软，仍可观察差异；原尺寸下的稳定可读性应特别关注 |
| 籍／藉、翼／冀 | 上部构件的差异保留；复杂字局部间隙在 sigma=1 时变弱 |
| 重点字五位置图 | 字形随整体平移，无明显截断；全部 81 字的位置边界另由自动检查覆盖 |

据此次观察，暂不需要改变首版字号、位置幅度或模糊候选值，可用这些值进入基线流程开发；它们还不是根据识别性能选出的最优参数。未因视觉印象删除字对，也未增加模糊强度以制造困难。

第二步“生成样张并检查字体与成像条件”的生成、自动核验及静态视觉初检已完成。下一步是在明确数据划分后，用普通交叉熵建立小规模分类基线，记录验证错误与运行成本；当前尚无准确率、混淆矩阵或方法改进结果。
